# 경영지원팀 대시보드

일감 관리 + 월간 반복 업무 체크리스트.

- 배포: https://jungsikson.github.io/bizsupport-dashboard/
- 데이터: Supabase `biz_task` / `biz_check` / `biz_comment` / `biz_routine`
  (오토랩 대시보드의 `autolab_*` 와 완전히 분리됨)
- 담당자: 정희진 · 박현아 · 전윤정 · 강라영

## 탭

| 탭 | 내용 |
|---|---|
| 오늘 대시보드 | 담당자별 일감 카드 + 월간 반복 업무 요약(지난 미완료·7일 내) |
| 업무 히스토리 | 담당자·기간별 완료/미완료 이력 |
| 월간 반복 업무 | 행=날짜, 열=담당자 격자. 규칙 1회 등록 → 매달 자동 전개 |
| 셀현황 | 셀현황(자동) 시트 실시간 조회 (읽기 전용) |
| 우선순위 매트릭스 | 담당자별 아이젠하워 4분면 |

## 반복 업무 규칙

- 기준일: 매월 지정일 또는 말일
- 주말 보정: 그대로 / 앞 영업일 / 뒤 영업일
- 완료 체크는 `월 단위`로 관리되어 매달 새로 시작됨 (`r{규칙id}_{YYYY-MM}`)

## 코드

`index.html` 단일 파일 (vanilla JS). 수정 후 main 에 push 하면 GitHub Pages 자동 반영.
